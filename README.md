## 👋 Sobre mí

Construyo software que resuelve problemas reales: plataformas web, firmware para microcontroladores, automatizaciones y agentes de IA. Fundador de **Ouroboros Software**.

- 🧠 **Full-stack** — .NET, Python, Node, SvelteKit, PostgreSQL, SurrealDB
- 🤖 **Robótica** — ESP32 / Arduino, telemetría, flasheo de firmware
- ⚙️ **Automatización** — Docker, n8n, Cloudflare, agentes IA
- 🎓 **Educación** — robótica y programación para colegios
